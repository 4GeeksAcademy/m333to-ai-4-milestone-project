# .agents

This directory stores repository-level agent guidance and reusable capability rules for the project.

## Scope

Rules and skills inside this folder are intended to be active project conventions rather than feature-specific documentation alone.

## Development rule

**Rule:** Any agent or skill added to this folder must be documented, scoped, and aligned to the monorepo’s business and technical context.

**Scope:** always active

This rule is applied across the repo because the instructions here define the default operating behavior for future agent work.
