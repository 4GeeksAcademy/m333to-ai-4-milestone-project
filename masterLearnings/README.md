# Master Learnings

This directory contains lesson-style markdown files created after each major implementation in the TrackFlow project.

## Purpose

Each lesson explains:

- why an implementation choice was made
- what was implemented
- how the implementation fits the architecture
- what can be learned from the approach
- what could be improved or extended next

## Naming convention

Use descriptive filenames with a sequence when useful, for example:

- `001-memory-bank-and-agent-rules.md`
- `002-website-and-backoffice-scaffolding.md`
- `003-backend-service-foundation.md`

Every lesson should be written for learning, not just as a changelog.
