# TrackFlow Website

This is the public-facing website for the TrackFlow logistics project. It is designed to communicate the company value proposition, operational visibility, and fulfillment intelligence in a polished, corporate-style landing page.

## Project purpose

The website acts as the front door for the business and gives visitors a clear view of:

- end-to-end parcel visibility
- warehouse-to-doorstep tracking
- service intelligence
- 24/7 operations coverage

## Local development

From this folder, run:

```bash
npm install
npm run dev
```

Then open the Vite local URL shown in the terminal.

## Notes

- A reusable component structure is used for branding and section headings.
- Styling is centralized in `src/styles.css` to keep the visual language consistent.
- This initial version focuses on the home route and corporate presentation.
