# TrackFlow Backoffice

This is the internal operations app for the TrackFlow project. It is intentionally separate from the public website and has a different layout, visual style, and focus.

## Purpose

The backoffice provides a working entry view for operational teams to monitor:

- shipment hubs and exception queues
- cross-region fulfillment activity
- customer support operational load
- international logistics coordination

## Visible business logic

The dashboard includes company-specific operational context from the TrackFlow brief, including:

- Los Angeles and Spain coordination
- warehouse-to-doorstep parcel movement
- 24/7 customer service coverage
- multilingual and cross-border operational considerations

## Local development

From this folder, run:

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.
